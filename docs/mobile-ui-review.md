# 利用者・団体画面の表示と操作の見直し

確認日: 2026-11-13

## 反映内容

- スマホの左右余白を16px、PCを24pxに統一。カード内の余白、見出し・本文・入力欄の開始位置も共通化。
- イベント一覧、プロフィールの設定、団体のメニュー・件数・イベント一覧を区切り線でまとめて整理。
- イベントカード全体を押して詳細を開けるようにし、保存ボタンは独立した44pxの操作範囲を確保。
- 検索結果を6件ずつのページ表示に変更。条件を変えると最初のページに戻る。
- プロフィールの月別実績を折りたたみ、保存イベントは最初の3件を表示。
- プロフィール編集が画面の端からずれる問題と、チャット入力欄が下部ナビに隠れる問題を修正。
- 団体の参加者管理、受付コード、活動報告の操作範囲とフォームを整理。
- 不要な説明、アカウントの認証・承認完了時の成功表示を削除。通常のログイン成功表示が出ないことも確認。

追加スタイルは利用者画面と団体画面に限定して適用。

## スクロールが長い箇所

390 × 844px、ローカルの確認用データで測定。表示内容や件数により変わる。

| 画面                     | ページ全体の高さ | 状況                                     |
| ------------------------ | ---------------: | ---------------------------------------- |
| 利用者・イベント検索     |        約1,900px | 6件ずつのページ切り替えで短縮            |
| 利用者・プロフィール     |        約1,200px | 月別実績と保存イベントの表示量を整理     |
| 団体・ホーム             |            844px | 1画面内                                  |
| 団体・企画作成の基本情報 |        約1,700px | 入力項目に応じた長さ。手順ごとに分割済み |
| 団体・参加者管理         |        約1,700px | 参加者なしの状態。申請が増えると長くなる |
| 団体・イベント一覧       |        約2,600px | 10件表示。修正前の約9,800pxから短縮      |

団体のイベント一覧は、初期50件を取得し、画面には10件ずつ表示する。検索・状態・並び順の変更時は先頭ページに戻る。追加確認では390px幅で全体2,568px、約3画面分になり、各操作の44px以上のタップ領域を維持している。件数やタイトルの長さにより高さは変わる。
