# Aizu Connect 法務・個人情報運用手順

最終更新日: 2026年10月17日

この文書は、利用規約とプライバシーポリシーを実際の運用へ反映するための内部手順です。法的助言そのものではないため、正式公開前および事業内容を変更するときは、運営主体を確定したうえで日本法の専門家による確認を受けてください。

## 1. 公開前の必須確認

- 本番環境の `VITE_LEGAL_OPERATOR_NAME`、`VITE_LEGAL_OPERATOR_ADDRESS`、`VITE_LEGAL_REPRESENTATIVE`、`VITE_LEGAL_CONTACT_EMAIL` が実在する運営主体の情報になっていることを確認する。
- 問い合わせ先メールを毎営業日確認できる担当者を決める。
- 有料イベントは、販売・役務提供事業者名、責任者、住所、電話番号、参加費、追加費用、支払方法・時期、提供時期、キャンセル・返金条件が申込直前画面に表示されることを確認する。
- 主催者へ、参加者情報の目的外利用、無断転載は禁止転載、無断勧誘を禁止することを説明する。

## 2. 個人情報に関する請求

1. 受付日時、請求内容、対象アカウント、受付担当者を管理者案件として記録する。
2. 登録メールへの確認など、必要最小限の方法で本人または法定代理人を確認する。パスワード、本人確認書類の不要な写しは受け取らない。
3. 開示、訂正、削除、利用停止、第三者提供停止のどれに該当するかを整理する。
4. 法令上保存が必要な記録、他者の権利、調査・紛争対応への影響を確認する。
5. 対応内容または対応できない理由を本人へ連絡し、完了日時を記録する。

## 3. 漏えい・不正アクセス時

1. 影響拡大を止める。対象アカウントの停止、権限の無効化、公開範囲の制限、認証情報の失効を必要な範囲で行う。
2. ログを消さずに、発生日、検知日時、対象情報、対象人数、原因、第三者取得の可能性を記録する。
3. 個人情報保護委員会への報告対象かを直ちに判定する。報告対象の場合は、把握後おおむね3〜5日以内の速報、原則30日以内（不正目的のおそれがある場合は60日以内）の確報を運用目標とする。
4. 本人通知が必要な場合は、事実、対象情報、原因、二次被害防止策、問い合わせ先を速やかに知らせる。
5. 復旧後に原因と再発防止策を記録し、Security Rules、管理権限、ログ、主催者運用を見直す。

## 4. 要配慮個人情報

- 主催者が健康、障害、病歴等を尋ねる必要がある場合だけ、申込質問の「健康・障害等の要配慮情報を含む」を有効にする。
- 参加者の明示同意がない申込は受け付けない。
- 回答は安全確保・必要な配慮のためだけに使い、チャットや活動報告へ転載しない。
- 不要になった回答は、法令・事故・紛争対応に必要な記録を除いて削除または匿名化する。

## 5. 写真・活動報告

- 公開前に、撮影者の権利と、識別可能な被写体への説明・必要な同意を確認する。
- 未成年者、名札、住所、車両番号、健康情報などが写る写真は特に慎重に確認する。
- 同意を撤回したいとの連絡があった場合は、本人確認後、対象写真を速やかに非公開化して対応を記録する。

## 6. 保存期間の見直し

- 第三者提供記録は `expiresAt` により提供から原則3年間保存する。
- 受付コードの失敗記録など期限付きの安全管理データは、定期Functionで期限到来後に削除する。
- 通報、審査、管理操作、同意、チャット、活動実績は一律に自動削除せず、法令、事故、紛争、他の参加者への影響を確認して年1回以上必要性を見直す。
- 新しい保存項目を追加するときは、目的、閲覧者、保存期間、削除方法を決めてから実装し、プライバシーポリシーも更新する。

## 7. サービス範囲を広げる場合

求人・職業紹介、旅行の手配、寄付募集、継続課金、オンライン決済、酒類・食品販売などを追加する前に、該当する業法、許認可、表示義務、年齢制限を個別に確認する。確認が終わるまで該当機能を公開しない。
