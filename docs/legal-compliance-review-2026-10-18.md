# Aizu Connect 法務対応レビュー（2026年10月18日）

## 今回対応した項目

- 利用規約・プライバシーポリシーを2026年10月17日版へ更新し、有料イベント、要配慮個人情報、未成年者、活動報告写真の取扱いを実装と一致させた。
- 現地現金払いを含む有料イベントの申込直前画面に、事業者、責任者、住所、電話番号、総額・追加費用、支払方法・時期、提供時期、申込期限、キャンセル・返金条件、契約成立時点を表示した。
- 主催者が健康・障害等を含む申込質問を明示できるようにし、該当回答がある場合は別個の明示同意を必須化した。Functionsでも同意なしの申込を拒否し、第三者提供記録へ対象区分を保存する。
- 規約同意と、18歳以上または16・17歳で法定代理人同意を得た旨の確認を別のチェック項目にした。
- 活動報告の公開前に、本文・写真の権利および被写体への説明・必要な同意の確認を必須化し、Security Rulesでも確認済みの書込みだけを許可した。
- 個人情報開示等請求、漏えい、不正アクセス、写真削除、保存期間見直しの運用手順を整備した。
- 本番依存パッケージの一覧と、インストール済みパッケージが同梱するライセンス・NOTICE本文を公開物として生成するようにした。

## 公開後も必要な運用

- 本文は一般的な法令対応の実装であり、法的助言や違法性がないことの保証ではない。運営主体、イベントの実態、主催者との契約、対象利用者を確定したうえで専門家の確認を受ける。
- 法定代理人同意と写真同意は、現状では利用者・主催者による確認記録である。高リスクイベントや16・17歳の利用が多い場合は、保護者へ直接確認する運用を追加する。
- 求人・職業紹介、旅行手配、寄付、継続課金、オンライン決済、酒類・食品販売等へ範囲を広げる前に、該当する業法と許認可を個別に確認する。
- ライブラリ更新時は `npm run legal:notices` を実行し、公開されるライセンス表示を更新する。
